# 美股動能篩選器 — 設計文件

**日期：** 2026-05-07  
**技術棧：** Python、yfinance、customtkinter、matplotlib

---

## 概述

一個桌面工具，每日篩選 S&P 500 中動能最強的標的。使用者手動觸發刷新，工具在背景抓取資料並計算綜合動能評分，以排行表展示結果，點選個股可查看走勢圖。

---

## 專案結構

```
stock-tool/
├── main.py               # 程式進入點
├── data/
│   ├── universe.py       # S&P 500 股票清單
│   └── fetcher.py        # yfinance 批次抓取，回傳標準化 DataFrame
├── scoring/
│   └── engine.py         # 指標計算、百分位排名、加權評分
└── ui/
    ├── app.py            # customtkinter 主視窗，管理 thread 與 queue
    ├── table.py          # 排行榜表格元件
    └── chart.py          # matplotlib 個股走勢圖元件
```

## 資料來源

- **套件：** yfinance（免費，資料延遲約 15 分鐘）
- **股票池：** S&P 500（約 500 檔），清單從 Wikipedia 或 hardcode 維護
- **抓取內容：** 每檔股票近 60 個交易日的 OHLCV 日線資料

---

## 評分引擎

### 指標與權重

| 指標 | 說明 | 權重 |
|------|------|------|
| 當日漲幅 % | `(close - prev_close) / prev_close` | 30% |
| 5 日漲幅 % | 近 5 個交易日累積報酬 | 20% |
| 20 日漲幅 % | 近 20 個交易日累積報酬 | 20% |
| 成交量爆量倍數 | 今日量 / 20 日均量 | 20% |
| RSI(14) | 相對強弱指標 | 10% |

### 計算流程

1. 對每個指標在 S&P 500 全體中做**百分位數排名**（0–100），消除尺度差異
2. 加權平均得到 `momentum_score`（0–100）
3. 依分數降序排列輸出

### 邊界情況

- 上市未滿 20 天的股票：缺少指標的欄位設為 0 分
- yfinance 單檔抓取失敗：跳過該股，記錄 log，不中斷整體流程

## UI 設計

### 佈局

兩欄式主視窗：

```
┌─────────────────────────────────────────────────────┐
│  美股動能篩選器          [刷新]  狀態：上次更新 10:32  │
├──────────────────────────┬──────────────────────────┤
│  排行榜（左半）           │  走勢圖（右半）            │
│  # | 代碼 | 名稱 | 評分  │                          │
│  1   NVDA  ...   94.2   │   [matplotlib 圖表]       │
│  2   META  ...   91.7   │   點選左側個股後顯示        │
│  3   AAPL  ...   88.3   │   近 60 日收盤價走勢       │
│  ...                    │                          │
│  （可點擊欄位標題排序）   │                          │
└──────────────────────────┴──────────────────────────┘
```

### 互動行為

- **刷新按鈕：** 觸發背景 thread 抓取資料；刷新中按鈕變灰並顯示進度（抓取中 X/500）
- **表格排序：** 點擊欄位標題切換升/降序，預設依 `momentum_score` 降序
- **走勢圖：** 點選表格任一列，右側更新為該股近 60 日收盤價走勢
- **防重複刷新：** 刷新進行中禁用按鈕，避免同時開啟多個 thread

## 資料流

```
使用者按「刷新」
    → app.py 啟動背景 thread
    → fetcher.py 批次從 yfinance 拉 500 檔資料（約 30–60 秒）
    → engine.py 計算評分並排名，回傳 DataFrame
    → queue 將結果送回主 thread
    → table.py 更新排行表
    → 使用者點選個股
    → chart.py 繪製近 60 日走勢圖
```

---

## 錯誤處理

| 情境 | 處理方式 |
|------|---------|
| 網路失敗（單檔） | 跳過該股，記錄 log，繼續抓其他股 |
| 全部抓取失敗 | 主 thread 顯示錯誤訊息 |
| 資料不足（新股） | 缺失指標設為 0 分 |
| 重複刷新 | 刷新中禁用按鈕 |
| UI 凍結 | 所有網路操作在背景 thread，queue 回傳進度 |
